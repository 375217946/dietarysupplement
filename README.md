# 保健品 & 补剂证据审查

逐款查一查常见保健品和补剂：哪些有人体临床证据，哪些基本是智商税。

**在线查看：<https://375217946.github.io/dietarysupplement/>**

## 这是什么

一个单页网站，目前收录 45 款补剂。每一款都包括：

- **证据等级**：按人体随机对照试验（RCT）的质量和结论打分，分为四档
  - **A 证据扎实**：大型高质量 RCT 支持，对目标人群确实有效
  - **B 有条件有效**：只对特定人群或剂量有效，或者证据有争议
  - **C 证据薄弱**：以动物、体外实验为主，人体只有小样本或厂商资助的研究
  - **D 基本智商税**：高质量研究的结论是无效
- **证据说明**：现有研究到底说明了什么
- **宣传问题和风险**：常见的夸大、错误引用、安全隐患
- **适合谁**：哪些人可能真正用得上
- **研究原文**：期刊原文（DOI）、PubMed / PMC 链接

页面支持按等级筛选，也可以按品名或成分搜索。

## 欢迎大家补充 🙌

内容一定有不全或过时的地方，欢迎一起完善：

- **新增产品或成分**：想看的补剂还没收录
- **更新证据**：有新的 RCT、荟萃分析或指南发布
- **纠错**：等级打得不对、引用有误、链接失效
- **补充风险信息**：药物相互作用、禁忌人群、监管动态

### 怎么参与

1. **提 Issue**：在 [Issues](https://github.com/375217946/dietarysupplement/issues) 里写下产品名、你的意见和参考文献链接。不会用 Git 也没关系。
2. **提 Pull Request**：所有内容都在 `index.html` 里，数据集中在脚本开头：
   - `D` 数组：每款产品一行，格式为 `[编号, 名称, 月价格, 原宣传强度, 等级, 证据说明, 问题/风险, 适合谁]`
   - `R` 对象：每款产品的参考文献，格式为 `[文献标题, 链接]`

   改完后直接用浏览器打开 `index.html` 就能预览。

### 补充时请注意

- 优先引用**人体 RCT、系统综述或荟萃分析、权威指南**，并附上原文链接（DOI 或 PubMed 最好）。
- 动物实验、体外实验和厂商资助的研究可以提，但请注明。
- 请保持客观，不做商品推广。
