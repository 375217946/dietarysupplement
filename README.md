# 45 款保健品 & 补剂：哪些有临床证据，哪些是智商税

逐款审查市面上常见的保健品和补剂。等级按人体随机对照试验（RCT）的质量和结论来打，并和商家常见宣传里的"科研支撑强度"放在一起对比。

**👉 在线查看：<https://375217946.github.io/dietarysupplement/>**

## 结论

**真正有硬证据的只有 3 款**（维生素 D 两款、一水肌酸），而且只对"对的人"有用。

| 等级 | 含义 | 数量 |
| :---: | --- | :---: |
| 🟢 **A 证据扎实** | 大型高质量 RCT 支持，对目标人群确实有效 | 3 |
| 🔵 **B 有条件有效** | 只对特定人群或剂量有效，或者证据有争议 | 15 |
| 🟠 **C 证据薄弱** | 以动物、体外实验为主，人体只有小样本或厂商资助的研究 | 22 |
| 🔴 **D 基本智商税** | 高质量研究的结论是无效 | 5 |

**宣传普遍夸大。** 商家给这些产品标的"科研支撑强度"没有一款低于"中等"，还常引用不存在或张冠李戴的研究：

- "2019 年 JAMA 南非醉茄研究"并不存在；
- "2020 年 Cell Metab 老年女性骨密度研究"其实是小鼠实验。

这类内容很像 AI 生成的营销文案。按证据重新评估后，**45 款中有 41 款需要下调**。

## 几个普遍存在的问题

### 1. 把"体外/小鼠有效"当成"人体有效"

NMN、NR、AKG、亚精胺、PQQ、尿石素 A 这类"抗衰"成分，能提高血液里的某个指标是真的，但**没有任何一款被证明能延缓人类衰老**。美国国家衰老研究所的标准化小鼠测试里，NR 连小鼠的寿命都没能延长。

### 2. 借用别的产品的证据

- REDUCE-IT 试验证明的是**处方级纯 EPA、每天 4 克**的效果。普通鱼油、补充剂级 EPA 鱼油的成分和剂量都不同，不能套用。
- 益生菌的效果只对**具体菌株**成立。产品只写"可能含……"、不标菌株号，就对应不上任何一项研究。

### 3. 把药品当保健品卖

小檗碱（黄连素）、水飞蓟宾在国内是**药品**。有相应健康问题应该去看医生、规范用药，而不是自行买补剂。反过来，真正有证据的维生素 D、肌酸、B 族维生素，都是最普通的基础款。

### 4. 国内合规风险

国内只有获批的**"蓝帽子"保健食品**可以宣称保健功能，普通膳食补充剂不能宣传降糖、护肝、抗衰等功效。NMN 在 2021 年已被市场监管总局明确**未获食品类许可，不得作为食品生产销售**。

## 页面内容

每一款补剂都包括：

- **证据等级**：A / B / C / D，并与商家宣传的强度对比
- **证据说明**：现有研究到底说明了什么
- **宣传误区 / 风险**：常见的夸大、错误引用、安全隐患
- **适合谁**：哪些人可能真正用得上
- **研究原文**：期刊原文（DOI）、PubMed / PMC 链接

页面支持按等级、类别筛选，可以搜索成分、功效或人群，支持深色模式；每款都有单独链接（例如 `#s30`），方便分享。

## 欢迎大家补充 🙌

内容一定有不全或过时的地方，欢迎一起完善：

- **新增产品或成分**：想看的补剂还没收录
- **更新证据**：有新的 RCT、荟萃分析或指南发布
- **纠错**：等级打得不对、引用有误、链接失效
- **补充风险信息**：药物相互作用、禁忌人群、监管动态

### 怎么参与

1. **提 Issue**：在 [Issues](https://github.com/375217946/dietarysupplement/issues) 里写下产品名、你的意见和参考文献链接。不会用 Git 也没关系。
2. **提 Pull Request**：所有内容都在 `index.html` 里，数据集中在脚本开头的 `DATA` 数组。每款一个对象，照着已有条目的格式追加即可：
   ```js
   {id:46, name:"成分名称", cat:"类别", claim:"商家宣传强度", grade:"A/B/C/D",
    ev:"证据说明", risk:"宣传误区或风险", who:"适合谁",
    refs:[["文献标题", "链接"], ["报道标题", "链接", 1]]}
   ```
   改完后直接用浏览器打开 `index.html` 就能预览，等级分布和统计数字会自动更新。

### 补充时请注意

- 优先引用**人体 RCT、系统综述或荟萃分析、权威指南**，并附上原文链接（DOI 或 PubMed 最好）。
- 动物实验、体外实验和厂商资助的研究可以提，但请注明。
- 请保持客观，不做商品推广。
